# SEO

Сайт — одностраничное React-приложение. Чтобы поисковики видели текст без выполнения JavaScript, HTML страниц отдаёт сервер.

## Как это работает

1. nginx (`nginx/conf.d/web_locations.inc`) отправляет запросы страниц (`/`, `/catalog`, `/game/<игра>`, `/game/<игра>/<раздел>`, `/reviews`, `/faq`, `/cashback`) в `api/routers/seo.py`.
2. `seo.py` берёт собранный `index.html` сайта (`dist-web`) и подставляет в него:
   - `<title>`, description, canonical, Open Graph;
   - разметку schema.org: Organization, WebSite, BreadcrumbList, ItemList товаров с ценами, FAQPage;
   - текст страницы внутри `#root`: заголовок, описание, разделы, цены, ссылки;
   - данные для React Query (`window.__INITIAL_DATA__`), чтобы сайт не запрашивал их ещё раз.
3. Браузер загружает React, и тот заменяет серверный текст живым приложением.

Ответы кэшируются на 5 минут, цены и новые игры появляются сами.

## Тексты

- Заголовки и описания по шаблону — `api/services/seo_content.py`: `game_seo` (страница игры), `category_seo` (страница раздела). Шаблон подставляет названия разделов, цену «от», кэшбэк.
- Ручные поля игры в админке перекрывают шаблон:
  - `seo_title`, `seo_description` — заголовок и описание для поисковой выдачи;
  - `seo_text` — текст «Как купить …» под товарами (абзацы через пустую строку);
  - `seo_aliases` — другие названия игры через запятую («Рейд, Raid SL»). Первые два попадают в описание страницы, а все — в поиск на сайте;
  - `meta.h1` — свой H1, если шаблон звучит не по-русски.
- Описание раздела (`Category.description`) показывается вверху страницы раздела.

## sitemap, robots, IndexNow

- `/sitemap.xml` и `/robots.txt` генерирует `seo.py` из БД.
- `submit_indexnow` (каждый день в 05:30) отправляет изменённые страницы в IndexNow, его использует Яндекс (`api/services/seo_feeds.py`).
- Обложки игр отдаются в WebP-превью (`miniapp/src/utils/thumb.ts`), обложка страницы указана в `primaryImageOfPage`, чтобы поисковик показывал правильную картинку.

## Правила

- Не скрывать текст от людей ради поисковиков. Списки ключевых слов без смысла Google считает спамом. Строку «Также ищут» по этой причине убрали.
- Данные в `__INITIAL_DATA__` должны совпадать с ответом API. Берите их тем же обработчиком, что использует API, — так сделано в `_data_common`.
- Коды подтверждения Яндекс.Вебмастера и Google Search Console — переменные `.env` `YANDEX_VERIFICATION` и `GOOGLE_SITE_VERIFICATION` (вставляются в `<head>` сервером).
